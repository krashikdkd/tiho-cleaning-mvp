# мягко — локальная статическая копия

Копия сайта подготовлена для GitHub Pages. Главная страница: `index.html`.

## Что работает

- Выбор мебели, расчёт предварительной стоимости и корзина.
- Форма заявки с экраном подтверждения.
- Кабинет владельца в `admin.html`: просмотр локально сохранённых заявок и изменение их статуса.
- Данные заявки остаются в `localStorage` браузера и не отправляются на сервер. Авторизации и серверной базы в этой копии нет.
- 3D-компонент оригинального сайта не включён в скачанные файлы; используется локальное изображение-превью.

## Публикация

Репозиторий можно публиковать через GitHub Pages. Публикация этой папки создаст публично доступную статическую копию. Для приёма реальных заявок, общей базы данных и защищённого кабинета нужен backend.
